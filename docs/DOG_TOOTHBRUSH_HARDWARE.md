# Hardware Specifications: CanineCare Pro (Smart Ultrasonic Dog Toothbrush)

## 1. Ultrasonic Motor System
The CanineCare Pro uses a high-frequency ultrasonic transducer to generate vibrations that break down plaque and tartar without the need for aggressive mechanical scrubbing.

| Feature | Specification |
|---------|---------------|
| **Frequency Range** | 20 kHz – 40 kHz (Optimized at 30 kHz for canine enamel) |
| **Vibration Amplitude** | 0.02mm – 0.05mm |
| **Operating Modes** | Gentle (Puppy/Small Dog), Standard, Deep Clean |
| **Noise Level** | < 45 dB (Ultra-quiet to avoid startling the dog) |
| **Safety Cut-off** | Automatic stop if excessive pressure is detected |

## 2. Power & Battery Management
Designed for long-lasting use and easy maintenance.

| Feature | Specification |
|---------|---------------|
| **Battery Type** | Lithium-ion Rechargeable |
| **Capacity** | 800 mAh |
| **Battery Life** | Up to 30 days (based on 2 minutes of use, twice daily) |
| **Charging Method** | Inductive Wireless Charging (Charging Base) / USB-C Emergency Port |
| **Charging Time** | 4-6 hours for full charge |
| **Indicator** | LED ring for battery level (Green/Amber/Red) |

## 3. Housing & Build Quality
Safety and durability are paramount, especially considering potential chewing.

| Feature | Specification |
|---------|---------------|
| **Material** | Medical-grade, BPA-free, non-toxic silicone; Food-grade ABS plastic |
| **Waterproof Rating** | IPX7 (Full immersion up to 1 meter for 30 minutes) |
| **Durability** | Chew-resistant reinforced internal frame |
| **Incentive Reservoir** | 5ml integrated tank for liquid treats/toothpaste |
| **Ergonomics** | Anti-slip textured grip for human handling; contoured for dog mouth access |

## 4. Connectivity & Sensors
Integration with the CanineCare companion app.

| Feature | Specification |
|---------|---------------|
| **Bluetooth** | BLE 5.0 (Low Energy) for mobile app synchronization |
| **Pressure Sensor** | Capacitive sensor to detect force against teeth |
| **Motion Sensor** | 6-axis Gyroscope/Accelerometer to track brushing coverage |
| **Firmware** | Over-the-air (OTA) updates supported via app |

## 5. Compliance & Safety
- **FDA/GRAS:** All materials contacting the dog's mouth must be FDA compliant or Generally Recognized as Safe.
- **EMC/FCC:** Certified for low electromagnetic interference.
- **Thermal Protection:** Battery temperature monitoring to prevent overheating.
