# Google I/O Tracker Skill
This skill provides tools to stay updated with the latest from Google I/O. It can monitor official websites, blogs, and summarize the content for quick consumption.

## Tools
- `web_monitor`: Fetches the latest updates from the Google I/O website and The Keyword blog.
- `summarizer`: Processes text content and extracts key announcements and takeaways.
